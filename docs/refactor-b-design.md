# B 批样板设计（2026-10-26，已执行）

> 范围：首页、L1-02 大波、L2-01 祭牙祭坛。目的不是换皮，是把页面从“数据面板”改成“先判断、后证据”的图解教程。五段编号不变，解析台六段不变。
>
> 执行结果见文末 §6。

## 1. 首页

结构：`下一步（一句结论 + 一个主动作）→ 学习路径图 → 章节 → 教练建议 → 数据状态`。

- 右侧学习路径画成三站：L0 基础 → L1 波次模型 → L2 副本实战。每章是一枚节点，当前下一章用金色标记。
- 去掉“已读 N / 总 N”和进度百分比：它们把学习页变成完成率面板，也不是用户要的观感。
- 每张章节卡加一个小型波次缩略图（L0 用四个知识节点；L1/L2 用实际目标数方块，超过 10 只截到 10 并保留原数字）。
- 保留一个主按钮，不再让 hero 按钮和第一章重复指同一个入口。
- 教练建议仍在主线之后，不插进 L0→L1→L2。

## 2. 章节页（L1-02 样板）

- 顶图带三格保留：路线位置 / 一条数字结论 / 动作判断。只回答“这一波长什么样、值多少、做什么”。
- ① 不再是四张指标卡：用一条“目标数刻度”图标出本档在 1–4 / 5–9 / 10+ 中的位置，阈值线只出现一次；时长明确标“模型假设”，移动与危险点收缩成约束注记，不冒充已量化的 DPS 代价。
- ② 主图保留开 / 不开两行，每个场景都有真实 DPS、n、CI。
- ③ 技能调整改成“优先级位置图”：每条改动显示它在 38 条 APL 表中的序号/位置（伪技能显示“循环入口”），再加一句理由与证据；不再用两列纯文字清单。
- ④ L1 只显示真实路线中的同档示例，标题写明“路线示例，不是唯一一波”；L2 才显示完整路线与地图。
- ⑤ 先给 headline 和 9 段时间轴；完整阶段表默认折叠，保留全部数据但降低首屏噪声。
- 全站仍是四档字号、720 栅格、14 间距；不引入专精专属色。

## 3. L2 副本页

- 顶部三格跟随“当前选择波次”：路线位置、该波增量、动作判断。
- ① 路线总览：14 根柱，高 = 怪数，色 = 开 / 看冷却 / 不开，点柱切波。
- ② 当前波细节：组成、目标数、一次爆发增量（来自对应 runId 对）、建议。
- ③ 仍是 L1 调整的映射，缺单独数据就标待补。
- ④ 只显示地牢平面图和一句“没有坐标，不标位置”；不重复逐波柱。
- ⑤ 同章节页，默认折叠全表。

## 4. 多专精一致性

暗牧与噬灭共用顶栏、卡片、740 内容之外的同一套 token（内容宽仍 720）、图表外壳、状态标签和空态。噬灭只替换名称、技能图标与数据，不做紫色专属皮肤。

## 5. B 批验收

- 首页不再出现“已读 N / 总 N”和进度百分比；只有一个主按钮指向下一章。
- L1-02 的第①③段有真实图形；第②段每个场景有真实 DPS；第⑤段数据全量保留但全表可折叠。
- L2 点 14 根柱任一都能更新顶部摘要、当前波细节和地图注记；没有坐标仍不标位置。
- 11 章门禁全绿；暗牧 / 噬灭切换后顶栏、720 栅格、四档字号一致；截图可供审。

## 6. 执行结果（2026-10-26）

- 首页改为三站学习路径 + 无文字节点；去掉 `.path-bar` 和“已读”，章节卡增加微型目标数图，当前章在路径和列表同时高亮。
- L1-02 第①段换成目标数分档刻度（7 只阈值线、当前档中心点）；第③段换成带 APL 序号的位置图；第⑤段 headline 和时间轴在前，完整 9 段表默认折叠。
- L2-01 第①段是 14 波可点路线条；第②段跟随选波显示组成、开/不开 DPS、CI 与两条 runId；第④段只给地形和当前波说明，不重复柱条、不标坐标。
- 图契约从 32 有图 / 18 缺图 / 5 不适用 → **41 有图 / 9 缺图 / 5 不适用**。
- `check:ui` 增加：首页无完成率、single hero CTA、11 个路径节点、L2 选波联动、窄屏无横向溢出、噬灭骨架页同宽同字号。
