# 页面写作规范（参照 NGA / Wowhead 教程）

> 适用：所有章节页、空态页、教练卡。写完对照下面六条自查。

## 1. 结构：先结论，后展开

NGA 和 Wowhead 的攻略都这么开：

```
一句话说清这页干什么（为什么值得看）
  ↓
三条以内的结论（可以照做的那种）
  ↓
分节展开，每节一个小标题 + 一张图
  ↓
边界与例外（什么情况不适用）
```

不要按"我做了什么"的顺序写，要按"读者会怎么问"的顺序写。

## 2. 每节：图在前，文在后

- 先放图/表，标题写清这张图回答什么
- 正文只解释"图里看不出来的部分"，不复述数字
- 一节的正文不超过三句，超过就拆节

## 3. 术语：第一次出现给一句大白话

Wowhead 的做法是加 tooltip；我们用「中文名 + 一句人话 + 英文键名」：

> 虚空形态（Voidform）：暗牧的爆发窗口，进去以后伤害和资源速度都提高。

不要出现没有解释的缩写和英文键名。

## 4. 句子：短、可执行

- 不写"注意""尽量""合理""视情况"
- 每条建议要能落到一个动作：**开打前 / 这一波 / 打完**
- 不用被动语态，不写"我们可以看到"

## 5. 空态与占位：给形状，不给形容词

不要写"暂无数据"、"敬请期待"。要写清：

1. 这页将来长什么样（**画出来**，哪怕是灰模）
2. 缺的是什么具体材料（profile？日志？路线？）
3. 补上它的步骤（3 步以内，可照做）

## 6. 排版：三档字号 + 一个强调色

| 层级 | 用法 |
| --- | --- |
| 大标题 30–34px | 一页只出现一次 |
| 小节标题 14–16px | 每节一个，带编号或图示 |
| 正文 13–14px | 行高 1.65 以上 |

强调色只用来标"结论/行动"，不用来装饰。数据用等宽字体，单位不省略。

## 7. 自检清单

- [ ] 首屏能读到一句结论？
- [ ] 每节都有图或表？
- [ ] 术语都有解释？
- [ ] 每条建议都能落到具体动作？
- [ ] 空态有形状而不是形容词？
- [ ] 三段以内说完一节了吗？
